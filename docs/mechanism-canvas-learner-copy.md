# Mechanism Canvas

Electron movement, made inspectable.

## A concerted substitution

Show the curved-arrow step for hydroxide reacting with bromomethane. Add every arrow that moves in the same elementary step, then check the bundle.

Your goal is to track the nucleophile's electron pair while preserving carbon's octet and accounting for the leaving group.

Choose a lone pair or bond as the electron source. Then choose its target atom.

## Draft controls

Add the full elementary step before checking it. You can remove any arrow from the draft, clear the bundle, or undo the last committed step.

Checking diagnoses the current draft without changing the molecule. A valid check can be committed. If you edit the draft afterward, check it again before committing.

## Interactive molecular geometry

Rotate and zoom the molecule to inspect its geometry. Bond length and order, electron-domain count, lone pairs, formal charge, and bond polarity all change what is drawn.

This is an explanatory three-dimensional model, not a quantum calculation, molecular-dynamics simulation, or predicted conformer.

## Data boundary

This prototype stores progress in this browser. It has no server, account, model call, or cloud sync.
